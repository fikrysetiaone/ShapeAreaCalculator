# Shape Area Calculator (Java)

A simple Java OOP assignment demonstrating inheritance, an abstract class, and method overriding.

## Classes
- `Shape`: abstract parent class that declares `calculateArea()`.
- `Circle`: calculates area using π × radius × radius.
- `Square`: calculates area using side × side.
- `Triangle`: calculates area using ½ × base × height.
- `Main`: creates one object of each shape and prints the areas.

## Run in IntelliJ IDEA
1. Open this folder as a project.
2. Open `src/Main.java`.
3. Click the green Run icon beside `main`.

## Example output
```text
Area of Circle: 153.94
Area of Square: 25.00
Area of Triangle: 24.00
```
